# Kredit dan sumber

Kit ini dikumpulkan dari berbagai kreator. **Kit ini bukan CC0.** Hak atas tiap suara tetap milik pembuat aslinya, dan lisensinya mengikuti sumber asli masing-masing.

## Kreator yang teridentifikasi dari metadata file
- **misterhorse.tv** — "Essential Sound Effects" (contoh: `HITS_028`, `GLITCH_047`)
- **Himanshu Mehra / Techno Mania** (contoh: `HITS_018`, `HITS_019`)
- **@adobebasics** (nama di arsip asli: "boom impact", "Boop Sound Effect By Techno")
- **InspectorJ** (`CAMERA_018`)
- **Henrik Neef** (`CAMERA_028`)
- **Anton Porsche** (`CLICKS_024`)
- Lainnya: FoolBoy Media, kanadaka, Free Audio Zone, Vanderz, Deer Edits

Sekitar 456 file tidak menyebut nama kreator, tetapi memiliki tag kata kunci ala library komersial (status `check`).

Daftar lengkap per file ada di `sounds.json`, kolom `license.source`, dan diringkas di `report.md` bagian "Lisensi".

## Arti kolom `license.flag`
- `blocked`: dikenali dari sumber berlisensi per pelanggan (misalnya Epidemic Sound). File seperti ini tidak dimasukkan ke repo publik.
- `check`: ada petunjuk sumber di metadata (nama kreator atau tag kata kunci ala library komersial). Pastikan lisensinya mengizinkan disebar.
- `clean`: metadata tidak menyebut sumber. Ini **bukan** jaminan bebas lisensi.

## Pemilik suara
Kalau kamu pemilik salah satu suara di sini dan tidak ingin suaramu ada di repo ini, buka *Issue* dengan nama file atau `id`-nya, dan suara itu akan dihapus.
